# docs

| Folder          | Contains                                                       |
| --------------- | -------------------------------------------------------------- |
| `architecture/` | How the system is put together and why                          |
| `decisions/`    | Architecture Decision Records (ADRs) — one per real choice      |
| `experiments/`  | Things tried, what happened, what was learned                   |
| `development/`  | Setup, conventions, and working notes                           |

Rule: when a technology is chosen, write the ADR before writing the code.
